# Seedance video playground

A minimal app for testing Seedance video generation with a reusable asset library.

## Setup

1. `cp .env.example .env.local` and fill it in — at minimum `MODELARK_API_BASE_URL`,
   `MODELARK_API_KEY` and one `MODELARK_MODEL_SEEDANCE_*` id.
2. `npm install`
3. `npm run dev` and open http://localhost:3000

## Using it

- **Upload** adds an image or video to your asset library. When the Assets API keys are
  configured it is also registered, so it rides as a trusted asset id instead of a raw
  url — which matters for photoreal images of people.
- **Click a tile** to attach it as a reference. Tiles are numbered in the order you pick
  them, and those numbers are what `Image 1`, `Image 2`, `Video 1` mean in your prompt.
- **Duration: Auto** sends no duration at all and lets the model choose.
- The **✕** on a tile removes it from the library index; it does not delete the stored
  file or the registered asset.

The library lives at `~/.modelark-starter-kit/film-agent-library.json` and is shared
with the full ModelArk Starter Kit if you also run that.

## Notes

Nothing in this app is generated by hand — it is assembled from the ModelArk Starter Kit
by `tools/build-playground.mjs`. Re-run that script against the kit to refresh it.
