# Designer · places and props

Draws the camera views a scene needs as edits of the place's plate, so every view is the same room in the same light.

Each `## step:` section below is the image instruction for one render. `{name}` placeholders are filled from the scene sheet at call time.

| Step | Does | Placeholders |
|---|---|---|
| view | the place plate → the same place from one camera position | {place} {landmarks} {from} |

## step: view

The exact place in [Image 1] — {place} — seen from a different camera position: {from}.
It is the same place: the same walls, surfaces, colours, props, set dressing and light as [Image 1]. Its fixed things stay where they are: {landmarks}. Turning the camera moves them in the frame; it never moves them in the room.
No people. A photographic, cinematic frame at eye height with natural perspective.
